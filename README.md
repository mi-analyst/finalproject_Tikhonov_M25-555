# ValutaTrade Hub 🏦

Профессиональная система симуляции торговли валютой с микросервисной архитектурой.

## 🚀 Возможности
* **Core Service**: Управление кошельками, транзакциями и пользователями.
* **Parser Service**: Автоматическое обновление курсов валют (с поддержкой истории).
* **CLI**: Удобный интерфейс командной строки.

## ⚙️ Настройка и Запуск

1. **Установка зависимостей:**
   ```bash
   make install
   ```


2. **Запуск проекта:**
```bash
make project

```


3. **Обновление курсов:**
Внутри CLI введите команду `update-rates`.

## 🧩 Архитектура

Проект разделен на слои:

* `core/`: Бизнес-логика (User, Wallet, Portfolio).
* `infra/`: Работа с файловой системой (Singleton Settings & Database).
* `parser_service/`: Работа с внешними API.

## 💡 Кэширование и TTL

* Курсы валют кэшируются в `data/rates.json`.
* Время жизни кэша (TTL) настроено в `settings.py` (по умолчанию 5 минут).
* Исторические данные сохраняются в `data/exchange_rates.json`.

## 🔑 Конфигурация API

Для работы парсера используются открытые источники. Если требуется API ключ, установите переменную окружения:

```bash
export EXCHANGE_API_KEY="your_key"

```
